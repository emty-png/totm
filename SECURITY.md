# Security Policy

## Supported versions

`totm` is pre-1.0. Security fixes land on `main` and the latest tagged release only.

| Version | Supported |
| ------- | --------- |
| main / latest tag | :white_check_mark: |
| older tags | :x: |

## Reporting a vulnerability

Open a private security advisory on GitHub, or email the maintainers
(see commit history for contacts). Include:

* affected version / commit
* steps to reproduce
* impact (what an attacker gains)

We aim to acknowledge within 72 hours, fix and disclose once a patch is ready.
Please do not open public issues for unpatched vulnerabilities.
