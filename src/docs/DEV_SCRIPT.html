1 · Run model

Three tabs share one Run: HTML parses to elements, CSS cascades over HTML presentation attributes, and a non-empty JS tab evaluates in a sandboxed helper process first — then everything applies together in one undo entry. Generated nodes are tagged script: re-runs replace same-tag nodes, hand-drawn nodes are never touched. HTML/CSS-only runs apply synchronously; JS runs async with a 3 s watchdog (Stop / keep waiting).

  • Ownership: scriptId === "script" marks generated nodes at any depth (groups included).
  • Persistence: the three tabs save with the design; Ctrl+Z rewinds nodes but keeps your code.
  • Export-safe: video/PNG/SVG export renders plain scene data — code never runs at export.
  • Limits: each tab holds up to 256K characters; a run creates at most 2,000 shapes, 500 groups, 2,000 animations and 3,000 nodes total. Oversize runs fail with a console error instead of stalling.
  • Media privacy: scripts only ever learn library blob names, never file paths (picks go through the host picker).

2 · HTML reference

One element per line. Both "..." and '...' quotes work; attribute names may contain dashes (e.g. stroke-width).

TagNotes
<rect> <ellipse> <triangle> <star>x y w h (default 0 0 100 100), fill (color or linear-gradient()), rotation/rotate, name, class, plus presentation attrs below.
<text>...</text>Same box attrs; inner text is the content (closing tag required).
<img src> <video src>src names a library blob (hard error when missing). Geometry + rotation/opacity/radius/effects apply.
<pen points closed>points="x1,y1 x2,y2 ..." (2+ absolute points), closed="true|false". Box derives from the path bbox.
<audio src t0 duration>Timeline clip, not a node. duration in seconds is required (keeps HTML sync; JS probes instead).
<g name class> ... </g>Nests one level per line; groups nest arbitrarily. <g .../> is an empty group. Unclosed groups error but keep partial children.

Presentation attributes (lowest-priority style layer — any CSS rule wins): opacity radius fill-opacity stroke stroke-width stroke-position stroke-opacity layer-blur background-blur grain shadow glow shader shader-mode font-family font-size font-weight font-style text-decoration text-transform text-align.

3 · CSS reference

Selectors: rect ellipse triangle star text img video pen audio g, .class (matches the class word list), #name (matches name). Specificity: #name (3) > .class (2) > type (1); ties go to the later rule. Unknown selectors warn; rules with no usable selector error. One bad rule never kills the sheet; unmatched rules report Selector matched nothing.

4 · JS API

The totm object only (plus stock JSON/Math): no filesystem, no network, no app internals. Calls collect validated ops; QML applies them through the normal factory/animation path. Handles 0..N-1 index pending creates; totm.find() results carry a high bit and resolve by name at apply time.

CallNotes
rect/ellipse/triangle/star/text({...}){x,y,w,h,rotation,fill,name,opacity,radius,fillOpacity,stroke,strokeWidth,strokePosition,strokeOpacity,layerBlur,backgroundBlur,grain,shadow,glow,shader,shaderMode} + text {content,fontSize,fontFamily,fontWeight,fontStyle,textDecoration,textTransform,textAlign}. Gradients via fill: "linear-gradient(...)".
pen({points, closed, ...})points: [{x,y}] or [[x,y]] (2+ required).
image/video(blob, {...}) audio(blob, {t0, duration})Blob names only; missing blobs error at apply. Audio without duration is probed async.
pickImage/pickVideo/pickAudio({...})Phase 1 records the request; the panel shows one row per file and replays automatically when all are chosen. Cancel leaves no trace.
group(name, [handles])Only fresh create-handles (find results cannot be grouped); each handle groups once.
find(name)First top-first node with that name (groups included), resolved at apply time.
set(handle, {fill,opacity,radius,fillOpacity,x,y,w,h,rotation,name})Scalar mutation of created or found nodes. Runs before animates; missing targets warn.
remove(handle)Deletes created or found nodes (subtrees included). Runs before sets/animates so they warn instead of orphaning clips.
animate(handle, preset, {t0,duration,mode,options,easing})Any preset id — including custom from-to ids (customMove, customScale, customRotate, customOpacity, …) with their options passthrough, same as the gallery.
setDuration(seconds)Composition length.

6 · Samples

Grouped card with a gradient, styled text, and a preset:

<g name="card">
  <rect x="40" y="40" w="320" h="180" name="bg" class="panel"/>
  <text x="64" y="100" w="272" h="40">Hello</text>
</g>
.panel { fill: linear-gradient(90deg, #ff0000 0%, #0000ff); radius: 12; shadow: #80000000 0 4 16 0; }
text { font-size: 28; text-align: center; }
const bg = totm.find("bg");
totm.set(bg, { radius: 16 });
totm.animate(bg, "customMove", { duration: 1.2, options: { fromX: 0, fromY: 24, toX: 0, toY: 0 } });
const dot = totm.ellipse({ x: 400, y: 100, w: 48, h: 48, fill: "#0d99ff", glow: "#0d99ff 16 4" });
totm.animate(dot, "fade", { duration: 0.8 });

7 · Testing & troubleshooting

  1. Write HTML, press Run: shapes land as script-owned nodes (one undo entry); the console lists errors first with tab + line.
  2. Add CSS: unmatched selectors warn (Selector matched nothing); bad values warn and keep the attribute/default.
  3. Add JS: the worker evaluates off-thread; file needs open the pick flow (choose one per row, Cancel aborts cleanly).
  4. Disable nothing — scripts have no permissions to review; re-Run replaces prior output, Ctrl+Z rewinds nodes but keeps code.

Broken runs stay partial: valid elements still land while errors point at exact lines. Unknown blobs are hard errors; over-long audio warns when it fits nowhere.
