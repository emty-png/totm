1 · Quick start

Plug-ins are plain QML plus a manifest — no compiler, no SDK. You get a folder:

<plugins>/com.example.grids/
  manifest.json
  main.qml
  ui/GridTool.qml
  ui/GridSection.qml

Install path

Copy your folder into the plug-in directory, then press the sparkle Rescan button in Settings → Plugin (or restart):

~/.local/share/tot/totm/plugins/<your-id>/   # Linux
# macOS / Windows: the empty-state hint in Settings → Plugin shows it

The folder name must equal the id in your manifest, or the plug-in is rejected.

Minimal manifest

{
  "id": "com.example.grids",
  "name": "Grids",
  "version": "1.0.0",
  "author": "You",
  "description": "Snap helpers and a panel readout.",
  "entry": "main.qml",
  "tier": "standard",
  "contributions": {
    "toolbarTools": ["ui/GridTool.qml"],
    "designSections": ["ui/GridSection.qml"]
  },
  "permissions": ["doc.read", "ui.slots", "plugin.storage"],
  "permissionReasons": {
    "doc.read": "Reads the selection to show its size.",
    "ui.slots": "Adds a toolbar button and a panel section.",
    "plugin.storage": "Remembers the grid spacing."
  }
}

On first scan totm shows an approval popup listing every permission with your reason. The user can untick anything (it may break the plug-in) and change their mind later via Review in Settings → Plugin. New plug-ins start disabled until approved.

2 · manifest.json reference

FieldRequiredNotes
idyesLowercase reverse-dns, [a-z0-9._-], ≤ 64 chars. Must equal the folder name.
nameyesShown in the manager, popups and suggestions.
versionnoShown as v1.0.0 on the card. Informational only.
author, descriptionnoShown on the manager card.
entrynoDefaults to main.qml. Must exist. (totm loads contribution files directly; the entry marks the root.)
tiernostandard (default) or advanced. Advanced is required for fullOverlay and shows a stronger trust warning.
contributionsnotoolbarTools[], designSections[], canvasOverlays[], fullOverlay. Relative .qml paths inside your folder; every file must exist.
permissionsnoSubset of the 11 known ids (§3). Unknown ids reject the plug-in.
permissionReasonsnoOne short “why” per permission, shown in the approval popup. Write these well — they are your install screen.
totmVersionnoInformational compatibility hint (e.g. >=0.1.0).

3 · Permissions

Every capability is gated by PluginStore.hasPermission(pluginId, "…"). Check before acting; disabled plug-ins fail every check.

IdWhat it gates
doc.readReading the injected doc (selection, nodes, scene props).
doc.writeMutating doc (move/add/restyle). Normal undo still applies — prefer small, undoable edits.
library.readReserved. No mediated API yet; the grant is recorded and shown.
library.writeReserved. No mediated API yet; the grant is recorded and shown.
images.useMediated image picks (§5). You only ever see the picked blob name, never a path.
audio.useMediated audio picks, same pattern as images.
settings.readFollow the theme via AppTheme.isDark. Nothing else is exposed.
export.hookSuggesting quality/fps shown in the export popup. You never drive the exporter.
ui.slotsToolbar tools, design sections and canvas overlays.
ui.fullOverlayFull-window overlay (needs the advanced tier). Keep it non-blocking: no full-fill MouseArea.
plugin.storageScoped key/value storage (1 MB cap) that lives in totm’s own settings — never the filesystem.

4 · UI slots

ContributionWhere it appearsInjected props (declare the ones you need)
toolbarTools[]Floating canvas toolbar, after the image tooldoc, pluginId (doc stays live on tab/switch)
designSections[]Design panel, after Effectsdoc, snapshot (selection with mixed-value helpers), pluginId
canvasOverlays[]Over the scene, under the chromedoc, zoom, offsetX, offsetY, pluginId
fullOverlayWhole window, above viewspluginId (read TabState/ToolState yourself)
Declare injected props exactly as property var doc / property string pluginId etc. The host sets them on load when present; anything undeclared is simply skipped.

Reactive tip: doc.rev is the mutation tick — reference it in a binding to refresh derived values on every document change:

text: {
    var tick = doc ? doc.rev : 0;   // dependency only
    var n = doc && doc.selectedTops ? doc.selectedTops().length : 0;
    return n + " selected";
}

5 · PluginStore API

Your only backend. Everything is permission-checked; denied calls return false / {}.

CallNotes
hasPermission(id, perm)Gate every action on this.
getValue(id, key, fallback) · setValue(id, key, value) · removeValue(id, key)Scoped storage (plugin.storage).
requestImage(id) · requestAudio(id)Opens the host picker; listen for onPicked(pluginId, kind, name).
imageUrlFor(id, name) · audioUrlFor(id, name) · imageInfoFor(id, name)Resolve only names you picked; anything else returns empty.
suggestExport(id, quality, fps) · exportSuggestion(id) · clearExportSuggestion(id)quality is sd|hd|4k, fps is 30|60. The export popup offers it with Apply — never automatic.
pluginList · plugin(id) · permissionCatalog()Read-only introspection for manager-style UI.

Use the host’s building blocks directly: ToolbarButton, PanelSection, SegmentedOption, AppIcon (kinds like star, plus, book), AppTheme.* colors.

6 · Sandbox rules

  • Imports: only QtQuick, QtQuick.Layouts, QtQuick.Controls, QtQuick.Shapes, QtQuick.Effects, Totm. Anything else (notably QtQuick.Dialogs, QtCore, QtMultimedia) rejects the plug-in.
  • Forbidden identifiers: LibraryStore, VideoExporter, SettingsStore, FileDialog, FolderDialog, StandardPaths, MediaPlayer, XMLHttpRequest, WorkerScript, LocalStorage, Qt.createQmlObject, Qt.openUrlExternally — even inside strings or comments. Go through PluginStore so permissions apply.
  • No network: remote http/https/ftp transport is denied engine-wide, so plug-ins stay offline by construction.
  • No raw files: UI loads through mediated URLs; state lives in scoped storage; media arrives as picked blob names.
  • One bad plug-in never blocks the rest — it shows a disabled card with the exact error.

7 · UI style rules

  • Colors: bind AppTheme.* only — never hardcode hex (dark and light themes come free).
  • Type: 12px default, 11px muted captions, DemiBold titles; elide: Text.ElideRight, qsTr() for strings.
  • Metrics: radius 6 fields/buttons, 8 toolbar buttons, 10 popups, 12 cards; 28px field height; 8px body spacing.
  • Delegates: keep them self-contained — pass data via properties, wire callbacks where the outer scope is visible (see §8).
  • Hygiene: one responsibility per file, 4-space indent, run qmlformat + qmllint before sharing.

8 · Full sample

A toolbar button that counts taps in storage and logs the live selection:

import QtQuick
import Totm

ToolbarButton {
    property var doc: null
    property string pluginId: ""

    iconKind: "star"
    onClicked: {
        if (!PluginStore.hasPermission(pluginId, "plugin.storage"))
            return;
        var n = Number(PluginStore.getValue(pluginId, "taps", 0)) + 1;
        PluginStore.setValue(pluginId, "taps", n);
        var selected = doc && doc.selectedTops ? doc.selectedTops().length : 0;
        console.log("tap " + n + " (selection: " + selected + ")");
    }
}

A design-panel section with a mediated image pick:

import QtQuick
import QtQuick.Layouts
import Totm

PanelSection {
    property var doc: null
    property var snapshot: null
    property string pluginId: ""
    property string mascot: ""

    title: qsTr("Mascot")

    Connections {
        target: PluginStore
        function onPicked(pickedId, kind, name) {
            if (pickedId === pluginId && kind === "image")
                mascot = name;
        }
    }

    Image {
        Layout.preferredWidth: 64
        Layout.preferredHeight: 64
        visible: mascot !== ""
        source: mascot === "" ? "" : PluginStore.imageUrlFor(pluginId, mascot)
        fillMode: Image.PreserveAspectFit
    }

    SegmentedOption {
        label: qsTr("Pick mascot")
        enabled: PluginStore.hasPermission(pluginId, "images.use")
        onClicked: PluginStore.requestImage(pluginId)
    }
}

9 · Testing & troubleshooting

  1. Copy the folder into the plug-in directory and press Rescan in Settings → Plugin.
  2. Approve permissions (try unticking one — the plug-in must degrade, never crash).
  3. Open a design: toolbar tool, panel section and overlay should appear; run your actions, then Ctrl+Z to confirm writes undo cleanly.
  4. Disable the plug-in in Settings → Plugin — its UI must vanish without errors.
  5. Deny a permission via Review — gated buttons must disable gracefully.

Broken plug-ins show a disabled card with the exact reason (bad manifest, missing file, forbidden import/identifier). The approval popup reopens automatically whenever an enabled plug-in is missing a grant.
